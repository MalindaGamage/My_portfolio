Malinda Gamage Portfolio

How to open locally

Option 1: Simple local server with Python
1. Open a terminal in `e:\My_portfolio`
2. Run `python -m http.server 5500`
3. Open `http://localhost:5500` in your browser
4. Save your HTML/CSS/JS changes, then refresh the browser to see updates

Option 2: Auto-refresh in VS Code
1. Install the `Live Server` extension in VS Code
2. Open the folder `e:\My_portfolio`
3. Right-click `index.html`
4. Click `Open with Live Server`
5. Your browser will refresh automatically when you save changes

Main files to edit
- `index.html` for content and sections
- `assets/css/style.css` for colors, layout, spacing, and visual polish
- `assets/js/main.js` for interactions
- `portfolio-details.html` for the project detail page

Notes
- This is a static site, so no build step is required
- If images do not update, hard refresh the browser with `Ctrl + F5`
